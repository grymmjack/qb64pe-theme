# Change Log

All notable changes to the "qb64pe-theme" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [Unreleased]

## [v0.4.1]
- Full-chrome UI theming for the generated preset themes: the entire window (activity bar, side bar, tabs, lists, inputs, peek views, diffs, gutter, minimap, terminal, …) is now derived from each scheme's palette (~196 keys), instead of the minimal set in 0.4.0.

## [v0.4.0]
- Added the 13 remaining QB64PE IDE preset color schemes as themes: Dark Blue, QB64 Original, Classic QB4.5, Dark Side, Camouflage, Plum, Cornfield, CF Dark, Broadcast, VS Code, X11 SgiColors, Light Green, and All White. Generated from the IDE's own scheme table (see `tools/generate-themes.js`); syntax colors match the IDE exactly. Light Green and All White are light themes.

## [v0.3.0]
- Added Super Dark Blue theme variation

## [v0.2.0]
